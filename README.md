# Koma Studio 1.0.0

スマートフォンで映像、写真、音声を編集するAndroidアプリ。Android 10（API 29）以降の arm64-v8a / x86_64 に対応します。素材をアプリ専用領域にコピーし、書き出したMP4を端末の Movies/Koma Studio に保存します。

## 最初の操作

1. 初回は本栖湖のサンプル作品が開きます。左上の KOMA から「新規プロジェクト」を選ぶと自分の作品を作れます。
2. 「素材」で端末の動画・写真を選択します。タイムラインのクリップをタップし「調整」でトリム、速度、構図、色、切替を設定します。
3. タイムラインの目盛りをなぞって再生位置を動かします。左右の再生ボタンは1フレーム単位です。時間表示をタップすると秒を直接指定できます。
4. 選んだブロックの両端をドラッグするとトリムできます。上端中央の短い線をドラッグするとクリップを並べ替え、レイヤーの開始位置を移動できます。
5. 字幕や子画面はプレビュー上でドラッグして配置し、2本指で大きさを変えられます。数値指定も可能です。
6. 「音声」でBGMを重ねるか、ナレーションを録音します。「字幕」でSRTを入出力できます。「重ねる」で写真や動画の子画面を追加します。
7. 「書き出し」で画角、解像度、fps、圧縮形式、画質を選びます。「360pで確認」でフェード、色、音量、ダッキングを最終出力と同じ処理で確認できます。通知や結果画面で進捗を確認・中止できます。

## 日本語の自動字幕

「字幕 → 日本語の自動字幕」で、音声を含む映像クリップまたは音声トラックを選びます。日本語音声モデルをAPKに同梱しており、初回だけ約100 MBを端末内に展開します。素材のトリム・速度・配置を反映した字幕案を確認し、必要な字幕を後から修正できます。

## 自動編集

「AI編集」では端末処理の縦型15秒、色と切替、音声調整を選べます。選択した動画の音量を解析して無音区間を取り除くか、シーン変化を解析して分割できます。音量しきい値や最短時間を調整できます。

GPTを使う場合は「AI編集」のアカウントで **Continue with ChatGPT** を押します。システムブラウザでサインインし、ChatGPTプラン利用を許可してアプリに戻ります。モデル一覧は接続したアカウントから取得します。編集指示、素材名、尺、設定を送信します。「代表画像も送る」を選んだ場合のみ、先頭6素材を上限に代表画像も送信します。撮影時の音声は送信しません。返ってきた操作を検証して変更一覧を表示し、適用後も一括で取り消せます。

ブラウザ経由の手順も用意しています。指示をコピーしてChatGPTを開き、回答のJSONをアプリに貼り付けて適用できます。これは手動の連携です。

## プロジェクト

作品は自動保存されます。左上のプロジェクト一覧から「素材込みで保存」を選ぶとオリジナルを含む .koma.zip を作れます。別の端末で「編集データを開く」から復元できます。軽量JSONは同じ端末の読み込み済み素材を参照します。書き出しは合成用の一時領域を使います。4K・60fpsやHEVCは端末性能と空き容量によって処理時間が変わります。出力は8-bit SDRです。

## ソースからビルド

Android Studioでこのフォルダを開き、JDK 17、Android SDK Platform 35、Android Gradle Plugin 8.9.2、Gradle 8.11.1 を使います。Gradleがインストール済みならプロジェクトのルートで `gradle assembleDebug` を実行できます。FFmpegKitをMaven Centralから取得します。配布APKはこのソースと同じSDK APIを使って javac、D8、aapt2、apksigner で署名したものです。各自のリリースビルドには各自の署名鍵を使います。

初回ビルドはVoskの日本語モデル `vosk-model-small-ja-0.22.zip` を取得し、SHA-256を確認してAPKに同梱します。モデルを取得済みなら `gradle assembleDebug -PkomaSpeechModel=/path/to/vosk-model-small-ja-0.22.zip` を使えます。ビルド済みのアプリは、字幕作成時にモデルをダウンロードする必要がありません。
